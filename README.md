# Flight Fare Optimizer
An interactive web application designed to compute and visualize optimal flight routes and minimal travel fares between connected airports using graph algorithms.

##  Features
* *Graph-Based Route Optimization:* Computes the shortest and most cost-effective paths between multiple destination nodes.
* *Algorithmic Pathfinding:* Powered by the *Floyd-Warshall Algorithm* to handle all-pairs shortest path calculations efficiently.
* *Interactive UI:* Dynamic input forms allowing users to select origin/destination cities and immediately recalculate routes.
* *Real-Time Output:* Instant visual updates

* *Frontend:* HTML5, CSS3, JavaScript (ES6+)
* *Algorithmic Core:* Floyd-Warshall Graph Pathfinding
* *Deployment:* GitHub Pages
